# 中国象棋 AI

一个纯浏览器端的中国象棋 AI 对弈程序,**单文件、零依赖、离线可玩**。

## 怎么玩

直接双击打开 `xiangqi.html` 即可(Chrome / Edge / Firefox 均可)。

- 点击己方棋子 → 绿色圆点为可走位置(红圈表示可吃)→ 点击落子
- 选择执红(先行)或执黑(AI 先行,棋盘自动翻转)
- 四档难度:简单(2 层 + 评估噪声)/ 中等 / 困难 / 大师
- 支持悔棋、新对局、将死/困毙/重复判和判定
- 右侧信息栏实时显示 AI 的搜索深度、评分、节点数、耗时

## 引擎架构 (v2 强化版)

| 模块 | 实现 |
|---|---|
| 搜索 | negamax + α-β 剪枝 + PVS 主变例搜索 + 迭代加深 + 将军延伸 |
| 剪枝 | 空着剪枝(null-move)+ 后期着法缩减(LMR) |
| 静态搜索 | 只延伸吃子着法,消除水平线效应 |
| 置换表 | Zobrist 哈希(固定种子),1M 表项 |
| 走法排序 | 置换表着法 → MVV-LVA 吃子 → 杀手着法 → 历史启发 |
| 评估函数 | 子力价值 + 经典调优位置表 + 士象完整度 + 残局过河兵增值 |
| 性能 | 整数棋盘编码 + 每层走法缓冲复用,约 80 万节点/秒 |
| 开局 | 内置微型开局库(中炮/飞相/起马/进兵随机) |
| 和棋 | 搜索内重复局面判 0 分,对局中三次重复局面判和 |

**v2 相比 v1 的提升**(同 2 秒思考时间):搜索深度 6 → 8+,
新旧引擎 500ms/步对抗赛 v2 以 4:0 获胜(见 match.mjs)。

AI 计算运行在 Web Worker 中(由 Blob URL 内联创建),界面不卡顿;
Worker 不可用时自动回退到主线程同步计算。

## 规则完整性

蹩马腿、塞象眼、对脸将(白脸将)、九宫限制、士象不过河、炮隔子吃子、
兵过河横走、困毙判负等规则均已实现,并通过 perft 基准验证:
初始局面走法数 **44 / 1920 / 79666 / 3290240**,与标准值完全一致。
